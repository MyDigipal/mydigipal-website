Récap technique · ce qu'il faut intégrer dans le repo

  • Ajouter la grille radiale --mx --my dans ServicesGrid.astro
  • Hook IntersectionObserver générique pour les data-target count-up
  • Encart calculateur léger sur la home (déjà page complète existante)
  • Wrapper SVG + bobs flottants dans IndustryCard.astro
  • Marker pill dans Header.astro (FLIP-style)
  • Marquee CSS-only avec respect de prefers-reduced-motion
  • Magnetic button comme primitive MagneticButton.astro
  • Scroll progress + reveal-on-scroll en util global (~ 30 lignes JS)
