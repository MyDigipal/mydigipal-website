Le code promo dans les tarifs

Quelqu'un du Club Protéine arrive par mydigipal.com/fr/academy?coupon=PROTEINE30. Aujourd'hui, la page lui annonce 290 € et 480 € : rien ne dit que son code est actif. Il ne découvre 203 € qu'à la page de paiement. Le code voyage bien, la vente n'est pas perdue, mais l'argument est invisible au moment où il compte.

Ce n'était pas le cas avant : l'ancienne page interrogeait le code et barrait le prix plein. La refonte des tarifs du 1er septembre ne l'a pas repris. Deux façons de le remettre, ci-dessous. Rien n'est déployé.

A — la pastille, comme la remise d'équipe

Le code prend la même forme que la remise d'équipe, sur la même ligne, en or au lieu du vert : la page a déjà ce vocabulaire, elle n'en apprend pas un second. Le prix plein est barré dans chaque carte, exactement comme il l'est déjà quand on prend plusieurs licences. C'est la reprise à l'identique de ce qui existait avant la refonte.

B — la pastille, plus une phrase qui dit d'où vient le code

Même chose, avec un bandeau au-dessus des cartes. Une remise dont on ne sait pas d'où elle vient inquiète autant qu'elle réjouit, surtout à 30 % : le bandeau nomme la séance et la date de fin, ce qui répond aussi à « est-ce que j'ai le temps d'y réfléchir ». Il coûte une ligne de plus, et il ne s'affiche que si un code est actif.

Ce que ça coûte à construire

Peu de chose : la section des tarifs barre déjà le prix plein quand on prend plusieurs licences. Il s'agit d'ajouter au calcul un second facteur de remise, lu sur la route publique du code, et la pastille. Une trentaine de lignes, un seul fichier, et les deux langues. Le montant affiché continue de venir de l'application, jamais d'un calcul refait dans la page : deux calculs pour un seul prix finissent toujours par diverger.
